# Swastik Pradhan DevOps / SRE Portfolio

A dark-mode, dashboard-inspired portfolio for Swastik Pradhan, built with Next.js 16, TypeScript, Tailwind CSS, and Framer Motion.

## Local setup

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Environment variables

This portfolio does not require any environment variables for local development or deployment.

## Production build

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import the repository in Vercel.
3. Use the default Next.js settings.
4. Deploy.

The app is configured for a standard Vercel Next.js deployment and does not require extra runtime configuration.

## Resume download

A placeholder resume PDF is included in the public folder as `public/Swastik_Pradhan_Resume.pdf`.

Replace it with your real PDF before going live to ensure the resume download is accurate.

## Notes

- The contact form uses a `mailto:` fallback and is ready to be connected to a backend or form service later.
- The site uses custom metadata and an SVG icon for SEO and favicon support.
- The design is optimized for mobile, tablet, and desktop breakpoints.
